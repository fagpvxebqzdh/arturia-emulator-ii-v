## Overview

Arturia Emulator II V recreates the legendary E-mu Emulator II, the early digital sampler that defined the sound of 1980s electronica and pop with its gritty 8-bit sample playback.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia Emulator II V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **8-Bit Sampling** | Original 8-bit sample playback with authentic quantization noise |
| **Sample Library** | Recreated factory disk library with classic Emulator II sounds |
| **Filters** | Analog filters added to the digital sample playback for warmth |
| **LFO+Env** | Vibrato, tremolo, and filter envelope for expressive sample manipulation |
